Demo information · October 14, 2026

A workspace for exploration.

Welina’s GitHub Pages site demonstrates ABA analytics with fictional clients, programs, and observations. These pages describe the demo, not a production service agreement.

Use fictional information only

Use the workspace to explore measurement tools, chart controls, annotations, and exports. Do not enter personal health information or use the site as a patient-record system.

Not a clinical decision tool

Demo charts and notes are illustrative. They do not provide medical advice, diagnoses, or treatment recommendations. ABC records show observed context, not proof of a behavior’s cause.

No production or compliance claims

The static frontend runs on GitHub Pages. It does not host the .NET API, provide authenticated patient access, or establish HIPAA or other health-data compliance.

Records can change or disappear

Edits stay in your browser. Resetting the demo, clearing browser storage, or a fixture update can replace them. Download any fictional records you want to retain. The demo is provided for evaluation without a promised availability or retention period.

Source and feedback

Visit the project repository for source code and implementation details. Use the issue tracker for technical feedback, without including confidential information.
