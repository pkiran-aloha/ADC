# Self-hosted type

Variable Latin WOFF2 fonts sourced from the `@fontsource-variable/geist` and `@fontsource-variable/outfit` packages (retrieved October 14, 2026). Both fonts use the SIL Open Font License. The original licenses are included alongside the font files.

The app and static information pages serve fonts locally; no Google Fonts or other font/CDN requests are needed. `font-display: swap` keeps text available while assets load.
